✦ أرسل استجابتك إلى جدار المشاركات

🛡️ حفاظًا على الخصوصية، لا تُطلب أسماء الطالبات أو صورهن أو المرفقات في جدار الاستجابات العام.

🔒تُفحص المشاركات تلقائيًا قبل النشر؛ فتظهر المشاركات التي تجتاز الفحص الأولي للجميع مباشرة، وتُحال المشاركات الأخرى للمراجعة. يُرجى عدم كتابة الأسماء الكاملة أو أرقام الهواتف أو أي بيانات شخصية.

لكل فرد بصمة تصنع الأثر

اختَر صفتك وفعالية المبادرة، ثم شارك بفكرة أو رسالة أو عمل تطوعي.

  • 🎓 الطالبة: رسالة أو نشاط أو مبادرة سلوكية إيجابية.
  • 👪 ولي الأمر: اقتراح أو رسالة دعم أو مشاركة مجتمعية.
  • 📚 المعلمة: محتوى توعوي أو خطة نشاط أو إثراء.
  • 🏫 الإدارية: تنظيم الفعالية أو متابعة الأثر أو تطويرها.
